content = """PRACTICAL 3 – FRACTIONAL KNAPSACK USING GREEDY METHOD
======================================================

1. AIM
-----
To solve the Fractional Knapsack problem using the Greedy Method and find
the maximum value that can be placed in a knapsack of a given capacity.

2. PROBLEM STATEMENT
--------------------
We are given n items. Each item has:
- A value (profit)
- A weight

We are also given a knapsack with a fixed capacity.

The objective is to select items so that the total weight does not exceed
the knapsack capacity and the total value is maximized.

In Fractional Knapsack, we are allowed to take a fraction of an item.
This is different from 0/1 Knapsack, where an item must be taken completely
or not taken at all.

3. GREEDY APPROACH
------------------
The algorithm makes the locally best choice at every step.

Step 1: Calculate the value-to-weight ratio for every item.

        Ratio = Value / Weight

This ratio tells us how much value we get for each unit of weight.

Step 2: Sort all items in descending order of their ratios.
The item with the highest ratio is considered first.

Step 3: Start selecting items from the sorted list.

- If the complete item fits in the remaining capacity, take it completely.
- Subtract its weight from the remaining capacity.
- Add its value to the total value.

Step 4: If the complete item does not fit, take only the fraction that fits.

        Fraction = Remaining Capacity / Item Weight

        Added Value = Item Value x Fraction

After taking this fraction, the knapsack becomes full, so the algorithm stops.

4. EXPLANATION OF THE CODE
--------------------------

A. Header files
---------------
#include <iostream>
    Used for input and output operations.

#include <vector>
    Used to store the items dynamically.

#include <algorithm>
    Provides the sort() function.

using namespace std;
    Allows us to use standard library names without writing std::.

B. Item structure
-----------------
struct Item {
    int id;
    int value;
    int weight;
    double ratio;
};

- id: Stores the original item number.
- value: Stores the value or profit of the item.
- weight: Stores the weight of the item.
- ratio: Stores value divided by weight.

The id is important because sorting changes the order of items. The id
allows us to display the original item number after sorting.

C. compare() function
---------------------
bool compare(Item a, Item b) {
    return a.ratio > b.ratio;
}

This function is passed to sort(). It arranges items in descending order
of their value-to-weight ratio.

For example, a ratio of 6 is placed before a ratio of 4.

D. fractionalKnapsack() function
--------------------------------
double fractionalKnapsack(vector<Item>& items, int capacity)

This function receives:
- The list of items.
- The available knapsack capacity.

The ampersand (&) means the vector is passed by reference. This avoids
creating another copy of the vector. The function sorts the original vector.

First, sort() arranges the items by decreasing ratio.

A variable maxValue is initialized to 0. It stores the total value selected.

The for loop visits each item in sorted order.

CASE 1: Complete item fits
--------------------------
if (items[i].weight <= capacity)

If the item's weight is less than or equal to the remaining capacity:
- Add its complete value to maxValue.
- Subtract its weight from capacity.
- Display that the item is 100% selected.

CASE 2: Complete item does not fit
----------------------------------
Otherwise, only a fraction of the item can be selected.

fraction = (double)capacity / items[i].weight;

The type conversion to double is important. It ensures that division can
produce a decimal result instead of integer division.

The value contributed by the fraction is:

items[i].value * fraction

This value is added to maxValue. The item number and selected percentage
are displayed.

The break statement stops the loop because the knapsack is now full.

Finally, the function returns maxValue.

E. main() function
------------------
1. Read the number of items.
2. Check that the number of items is positive.
3. Create a vector to store all items.
4. Read each item's value and weight.
5. Store its original item number using id = i + 1.
6. Check that values are non-negative and weights are positive.
7. Calculate each item's ratio.
8. Read and validate the knapsack capacity.
9. Call fractionalKnapsack().
10. Display the maximum total value.

5. DRY RUN / EXAMPLE
--------------------
Consider the following items:

Item 1: Value = 60, Weight = 10
Item 2: Value = 100, Weight = 20
Item 3: Value = 120, Weight = 30

Knapsack capacity = 50

Calculate the ratios:

Item 1: 60 / 10 = 6
Item 2: 100 / 20 = 5
Item 3: 120 / 30 = 4

The sorted order is Item 1, Item 2, Item 3.

Selection:

Step 1:
Take Item 1 completely.
Weight used = 10
Value obtained = 60
Remaining capacity = 50 - 10 = 40

Step 2:
Take Item 2 completely.
Weight used = 20
Value obtained = 100
Remaining capacity = 40 - 20 = 20

Step 3:
Item 3 has weight 30, but only 20 capacity remains.
So take 20 / 30 = 2/3 of Item 3.

Value obtained from Item 3:
120 x (20 / 30) = 80

Total value:
60 + 100 + 80 = 240

Therefore, the maximum value is 240.

6. TIME AND SPACE COMPLEXITY
----------------------------
Let n be the number of items.

Time Complexity:
- Calculating ratios: O(n)
- Sorting items: O(n log n)
- Selecting items: O(n)

Overall Time Complexity: O(n log n)

Space Complexity:
- The vector stores n items: O(n).
- The sorting algorithm may use additional implementation-dependent
  stack space; the main storage for the items is O(n).

For the usual practical-exam analysis, Space Complexity is written as O(n).

7. WHY IS THIS A GREEDY ALGORITHM?
----------------------------------
At every step, the algorithm selects the available item with the highest
value-to-weight ratio.

It makes the best immediate choice without reconsidering previous choices.

This strategy gives an optimal solution for Fractional Knapsack because
items can be divided into fractions.

8. DIFFERENCE BETWEEN FRACTIONAL AND 0/1 KNAPSACK
-------------------------------------------------
Fractional Knapsack:
- An item can be selected completely or partially.
- Greedy method based on value-to-weight ratio gives an optimal solution.

0/1 Knapsack:
- An item must be selected completely or not selected.
- Fractions are not allowed.
- Greedy selection by ratio does not always give an optimal solution.

9. IMPORTANT VIVA QUESTIONS
---------------------------

Q1. What is the Fractional Knapsack problem?
Ans. It is an optimization problem in which we select whole items or
fractions of items to maximize total value within a fixed weight capacity.

Q2. Which technique is used?
Ans. Greedy Method.

Q3. What is the greedy choice?
Ans. Select the item with the highest value-to-weight ratio first.

Q4. Why do we calculate the ratio?
Ans. It tells us the value obtained per unit of weight.

Q5. Why do we sort in descending order?
Ans. So that the item providing the highest value per unit weight is
considered first.

Q6. Why is Fractional Knapsack optimal using Greedy?
Ans. Because an item can be divided, allowing us to fill remaining
capacity with the best available value per unit weight.

Q7. What is the time complexity?
Ans. O(n log n), mainly because of sorting.

Q8. What is the space complexity?
Ans. O(n) for storing the items.

Q9. Why is double used for ratio and fraction?
Ans. Because ratios and selected fractions can have decimal values.

Q10. Why is the original item id stored?
Ans. Sorting changes item positions. The id helps display the original
input item number.

Q11. What does break do?
Ans. It stops the loop after a fraction is selected because the knapsack
has become full.

Q12. What happens if capacity is zero?
Ans. No item is selected, and the maximum value remains zero.

Q13. Can this greedy method be used directly for 0/1 Knapsack?
Ans. No. Greedy by ratio is not guaranteed to give an optimal solution
when fractions are not allowed.

10. QUICK EXAM REVISION
-----------------------
Remember these five points:

1. Calculate ratio = value / weight.
2. Sort items in descending order of ratio.
3. Take the complete item if it fits.
4. Otherwise, take fraction = remaining capacity / item weight.
5. Add the selected value and stop when the knapsack is full.

Final complexity:
Time  = O(n log n)
Space = O(n)

The key idea is: choose the item that gives the maximum value per unit
of weight first.
